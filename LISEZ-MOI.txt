Crewmong Us dans DeadelusTV — lot à installer

1. GitHub Desktop : sélectionner DeadelusTV, Fetch origin puis Pull avant de copier les fichiers.
2. Sauvegarder public/index.html, public/assets/app.js et public/assets/config.js.
3. Copier public et docs à la racine du dépôt local ; fusionner les dossiers et remplacer les trois fichiers. Ne pas supprimer public.
4. Commit puis Push origin. Après déploiement : Ctrl + F5 et ouvrir Crewmong Us.

Statistiques et comptes : même Supabase, aucune migration de base. Se reconnecter avec les identifiants existants si nécessaire.
Pour invitation/récupération, vérifier dans Supabase les Redirect URLs : https://www.deadelustv.com/?crew_auth=1 doit être autorisée. Cette configuration n’est pas modifiée par le lot.
Détails et tests : docs/crewmongus-integration.md.
